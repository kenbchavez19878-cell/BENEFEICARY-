Service Overview

Existing Client Profile:

* Client ID
* Full Name
* Date of Birth
* Sex
* Civil Status
* Contact Number
* Address
* Barangay
* Existing Supporting Documents

Do not require re-entering profile information.

STEP 3:
Service Application Form

Display service-specific fields.

STEP 4:
Document Upload

Show required documents based on selected service.

STEP 5:
Submit Application
