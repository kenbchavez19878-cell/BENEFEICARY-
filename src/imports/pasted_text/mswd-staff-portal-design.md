Redesign and update the MSWD Staff Portal after login. This is the internal Program Management System (PMS) used by MSWD personnel and must be visually consistent with the existing MSWD Calabanga Public Portal, Beneficiary Registration Page, Login Page, and Beneficiary Dashboard.

IMPORTANT DESIGN REQUIREMENT

Do NOT create a different admin dashboard theme.

The Staff Portal must use the same design system as the public website.

Reuse:

* Government Blue primary color
* MSWD Green secondary color
* White background
* Same typography
* Same spacing system
* Same card components
* Same form styles
* Same buttons
* Same icons
* Same border radius
* Same accessibility standards
* Same responsive behavior

The entire system should feel like one unified MSWD Calabanga platform.

USER ROLES

The internal portal supports:

* Administrator
* Supervisor
* Staff

After login, these users should be redirected to the MSWD PMS Dashboard.

Beneficiaries must not access this dashboard.

If a Beneficiary attempts to access the Staff Portal, display:

Title:
Access Restricted

Message:
This area is only available to authorized MSWD personnel.

Button:
Return to Beneficiary Portal
